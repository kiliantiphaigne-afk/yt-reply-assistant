# YT Reply Assistant — For Later (Post-MVP)

## V2 — Engagement

- **Publication Chrome Web Store** : packaging, review Google, listing public, onboarding pour createurs random
- **Analytics d'engagement** : tracker si les reponses assistees generent plus de replies/likes que les reponses manuelles
- **Templates de reponses** : categoriser les commentaires (question, compliment, critique, suggestion) et proposer des templates adaptes
- **Reponses en batch** : mode "traiter tout" qui pre-genere les suggestions pour tous les commentaires visibles et permet de les valider en serie (accept/skip/edit)

## V3 — Multi-plateforme

- **Support multi-chaines** : gestion de plusieurs chaines YouTube avec des profils de style distincts
- **Reponses automatiques** : mode "auto-reply" pour les commentaires simples (remerciements) avec validation a posteriori
- **Detection de sentiments** : prioriser les commentaires negatifs ou les questions urgentes
- **Integration Shorts** : support des commentaires sur les YouTube Shorts (UI differente)

## V4 — Intelligence

- **Contexte cross-videos** : si un commentateur a deja commente d'autres videos, enrichir le contexte avec l'historique
- **FAQ auto-generee** : detecter les questions recurrentes et proposer des reponses standardisees
- **Suggestions proactives** : proposer des sujets de video bases sur les themes recurrents des commentaires
- **Export des insights** : dashboard avec les tendances des commentaires (sujets, sentiments, questions frequentes)

## Idees exploratoires

- Extension Firefox (portage via WebExtension API)
- Plugin pour d'autres plateformes (Twitch, Instagram, TikTok)
- Mode collaboratif : un community manager valide les reponses au nom du createur
- Integration avec un CRM createur (suivi des super-fans, top commentateurs)
